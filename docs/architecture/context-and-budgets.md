# 上下文、工具历史与思考预算

更新：2026-10-16。适用于当前 trylo-v1 源码；安装包与正在运行的进程需单独更新。

## 请求路径与所有权

`session journal → prompt-view → requestMessages → provider adapter → stream → tool execution → iteration gap`

CLI journal 保存原始事实；prompt-view 负责摘要窗口与历史投影；requestMessages 统一组装系统提示、工具目录与临时段；provider adapter 拥有原生思考续接和 wire 格式。Desktop 消费版本化协议，不维护第二个上下文引擎。

每次发送前（含首次输入和 resume）测量当前视图。系统提示 replace/append 与真实发送共享组装逻辑；最终请求再检查临时学习和报告段。超限通过现有有界压缩尝试恢复，仍无法容纳时明确返回 context_limit，保留用户约束和原 journal。

## 工具结果与恢复

最新尚未被模型消费的并行工具结果整批保留，避免只保留最后一个结果而丢失其他正文。旧大结果可投影成有标记的头尾片段，调用与结果始终配对。摘要不替代用户原始约束。

特定 GLM Chat 连接只复用实际收到、完整闭合并匹配身份的原生思考。原始参数与执行归一化参数分开保存；缓存有界、恢复缺失显式报告。显示层文本不能伪造原生状态。图片通过有界、校验过的文件引用进入请求，不把 base64 写成工具事件。

## 两类预算

| 项目 | 含义 |
| --- | --- |
| contextTokenLimit / provider contextWindow | 当前请求上下文的配置边界；未声明时不猜测模型窗口，也不会自动压缩 |
| --max-tokens | 整轮累计输出预算；每次请求发送剩余份额，思考已包含在 output/completion tokens 中 |
| reasoning effort | Provider 的思考档位；这次修复没有降低档位 |
| 事件边界 | 客户端流事件容量；与模型 token 预算独立，溢出必须停止读取并只产生一次失败终态 |

文字、参数、工具定义和原生思考采用统一 UTF-8 字节粗估，服务端 usage 单独保留；该估算不是模型 tokenizer。图片仍采用保守负载估算。前端显示的推测窗口不能替代后端声明。

## 本次验证与边界

新增回归先在未修复构建上失败，再通过修复后的检查。主目录 CLI 全部 11 步门禁通过，含 38 项合同测试、3971 个 hermetic 测试名。

独立 CLI 子进程实际读取两个文件，两个 24120 字符结果完整回传；原生思考续接、唯一终态和预算 `256 → 76` 同时通过，思考档位保持 high。响应由本机合成 SSE 提供，不证明真实模型的生成速度。真实 provider 长任务、安装版 Desktop、WebView2 和移动设备仍需分别验收。

当前同步还包含主目录已有的流合并、重复终态修复、真实压缩与上下文显示、启动准备优化，以及完成后的思考和回答界面改动。原始调试会话和内部排障档案不进入此公开源码快照。
