# 上下文、工具历史与思考预算

更新：2026-10-17。适用于当前 trylo-v1 源码；安装包与正在运行的进程需单独更新。

## 请求路径与所有权

`session journal → prompt-view → requestMessages → provider adapter → stream → tool execution → iteration gap`

CLI journal 保存原始事实；prompt-view 负责摘要窗口与历史投影；requestMessages 统一组装系统提示、工具目录与临时段；provider adapter 拥有原生思考续接和 wire 格式。Desktop 消费版本化协议，不维护第二个上下文引擎。

流适配器立即交付首段，后续片段以 128 字符或 40ms 计时触发刷新。定时刷新不另起第二次上游读取，提前返回会取消仍在等待的 HTTP reader；不需要等待响应 EOF 才展示短段思考。`tool_result.fileChanges` 是成功工具结果的可选、有界显示元数据，不能改变权限或原始会话事实。

每次发送前（含首次输入和 resume）测量当前视图。系统提示 replace/append 与真实发送共享组装逻辑；最终请求再检查临时学习和报告段。超限通过现有有界压缩尝试恢复，仍无法容纳时明确返回 context_limit，保留用户约束和原 journal。

## 工具结果与恢复

最新尚未被模型消费的并行工具结果整批保留，避免只保留最后一个结果而丢失其他正文。旧大结果可投影成有标记的头尾片段，调用与结果始终配对。摘要不替代用户原始约束。

特定 GLM Chat 连接只复用实际收到、完整闭合并匹配身份的原生思考。原始参数与执行归一化参数分开保存；缓存有界、恢复缺失显式报告。显示层文本不能伪造原生状态。图片通过有界、校验过的文件引用进入请求，不把 base64 写成工具事件。

## 预算维度

| 项目 | 含义 |
| --- | --- |
| contextTokenLimit / provider contextWindow | 当前请求上下文的配置边界；在声明窗口的 90% 处自动压缩，配置值仍是发送硬上限；未声明时不猜测窗口 |
| --max-iterations | 可选请求次数预算；普通执行不再默认设置 32 次上限 |
| --max-tokens | 可选整轮累计输出预算；显式设置后每次发送剩余份额，思考包含在 output/completion tokens 中；普通执行不再默认设置累计 65536 上限 |
| reasoning effort | Provider 的思考档位，遵循模型及用户配置；未降低档位，也未新增统一的单次思考额度 |
| 事件去重 | 执行日志分配稳定送达位置，状态机保存处理进度；普通执行不再受 4096 条事件限制，重复工具事件不重执行；旧无序号日志仍保留原来的有界保护 |

参考本地 Codex `73a1148` 的普通执行、模型配置及自动压缩语义；显式 rollout/account/server 限制与这些默认策略分别成立。现有用户配置中的预算值继续有效，本次不会自动清除。完整内部日志仍随事件增长占用内存。

文字、参数、工具定义和原生思考采用统一 UTF-8 字节粗估，服务端 usage 单独保留；该估算不是模型 tokenizer。图片仍采用保守负载估算。前端显示的推测窗口不能替代后端声明。

## 本次验证与边界

预算和长流回归先在未修复构建上失败，再通过修复后的检查。2026-10-17 主目录与独立公开候选 CLI 各自全部 11 步门禁通过，含 38 项合同测试、3994 个 hermetic 测试名；上轮预算专项 48 项回归保留在当前门禁中。

同一合成工作流的实际 CLI 进程对照：旧构建在第 32 次请求结束为 failed；源码构建、Desktop 内置版及公开候选均完成 41 次请求、实际读取 41 个不同文件，报告累计输出 82000，默认不发送 max_tokens，思考档位始终为 high。5000 段思考流与日志回放也通过。该对照只证明客户端执行合同，不证明真实模型提速。

上轮独立 CLI 子进程实际读取两个文件，两个 24120 字符结果完整回传；原生思考续接、唯一终态和预算 `256 → 76` 同时通过，思考档位保持 high。本轮联测另验证实际 CLI 的四种文件工具经过协议、聊天投影到真实落盘，以及 HTTP 响应尚未结束时的后续短段思考。响应由本机合成 SSE 提供，不证明真实模型的生成速度。真实 provider 长任务、安装版 Desktop、WebView2 和移动设备仍需分别验收。

预算、90% 压缩阈值和 journal 去重沿用 2026-10-16 对齐结论。本轮增加有时限的流刷新、文件改动事实投影、按需加载管理命令及文件工具修复。原始调试会话和内部排障档案不进入公开源码快照。
