# 正式记忆、原生续接与上下文更新

适用于本次融合源码。执行、记忆存储、模型续接和 Desktop 显示各自保留原有状态所有权；不把模型自报完成当作文件或记忆已提交。

## 正式记忆

显式记忆请求经过 CLI 正式记忆服务、工具和权限路径。读取、保存、更正和撤回使用同一事实存储，Desktop 面板通过 CLI 管理命令读取与修改，不再解析另一套本地存储格式。

事实有稳定 ID 和版本；更正、撤回及命令重放需验证作用域与期望版本。facts v2 保留撤回与幂等消费信息，旧 writer 不得覆盖新格式。读取/追加/压缩有字节、记录数和单行上限；损坏、超容量和锁失败显式报告，不把坏账当空账、不自动删旧事实。管理压缩与写操作共用锁及唯一 writer。

关闭学习、拒绝、无痕等条件继续约束写入。历史便签不自动变成正式记忆。显式普通项目文件请求走真实文件写入和读回，不能借“记住”创建未经要求的项目便签。宿主的有限指令解析有保守拒绝和本地分支，不是通用自然语言授权证明；本地命令的零 token 成功不算真实模型成功。

## 原生模型续接

续接数据按真实来源、身份与检查点绑定恢复。只有确证缺失的原生数据才计入降级；未知来源、原本没有及被拒收的数据分别表达，不把技术 occurrence 数叫作丢失了多少轮对话。

确证降级通过版本化协议显示中文提示；持久通知完成后才确认已送达，下一轮、子进程和重启不应重复刷同一通知。显示层文字不能伪造模型原生状态，正式记忆也不能授予执行权限。

## 默认上下文压缩

本次保留上游 PR #2 / #4：model 摘要只有显式正常结束才能提交；失败片段回退，取消沿压缩专用信号传递。HTTP reader 回收仅容忍和当前取消关联的错误，其他错误仍传播。

默认 extractive 摘要采用有界工具摘录，保留调用 ID、真实 outcome，以及白名单 read_file 的来源和范围。模型可以按摘录不足的提示重读来源。摘要按不可信历史数据引用，不能变成指令或权限来源。

摘录仍有损：区别行数量、长段和全局摘要上限可能淘汰事实；不声称消除所有任务漂移。上下文窗口、整轮输出预算和模型思考档位继续分开。普通执行没有隐含的 32 请求或累计 65536 输出限制；显式配置仍生效，声明窗口的 90% 触发提前压缩。

## 远程工作台与工程范围

网关更新处理端口占用、实际 listener 归属、并发启停、旧连接回收和关闭未完成 HTTP 请求。配对只展示当前有效服务的二维码，关闭、失败和迟到结果分别处理。手机端使用 Desktop 的权威快照和事件恢复，不因 WebSocket 刚打开就宣称已连接。

公开源码与本机原生 debug 候选、真实模型、最终安装包及手机设备验收是不同证据。本轮具体门禁、同步基线和限制记录在当前源码检查点；既有内部任务报告不自动证明这份融合源码的原生/真模型行为。
