## 本次源码与所有权

| 范围 | 当前行为与边界 |
| --- | --- |
| 浏览器 | 固定桌面/移动视口在既有 native browser owner 中设置，展示缩放与实际页面尺寸分别处理；页面、会话、输入映射和用户接管继续绑定同一目标 |
| 聊天与计时 | 计时归属用户 turn，并在完成、失败、取消或进程结束时收口；完成后的字体、行宽及工具卡呈现使用已有聊天投影 |
| 文件改动 | CLI 从成功工具结果投影有界 fileChanges 元数据；Desktop 校验并持久化结构化事实，展示创建、覆盖、补丁、删除、移动及 notebook 改动；缺少前像的覆盖不会伪造删除差异 |
| 用户学习面板 | 增加完整文档阅读、差异、源码及元数据视图；批量内容不完整、危险提案和过期 payload hash 沿用拒绝条件；CLI 学习与 Services/Hermes 数据来源沿用现有边界 |
| CLI 流与启动 | 首段仍立即交付；后续片段以 128 字符或 40ms 计时触发合并刷新，避免等到 EOF；管理命令按需加载，缩小普通启动的导入闭包 |
| 文件工具 | 支持单文件搜索目标、中文导航及 CRLF/LF 匹配；无行号补丁从未消费位置向后寻找，重复/歧义或乱序仍拒绝，文件保持原状态 |

`tool_result.fileChanges` 为 v1 的可选增量字段：旧生产者缺省时保留原显示路径；新消费者只接受受支持 kind，最多 64 项、路径长度 4096、合计预览 64000 字符。权限和工具执行仍由原 owner 决定，显示字段不能授予写入权限。

新增阅读器、文件改动解析与事实投影分别放入独立模块。现有 App 保留组装责任，新增时序观察者按 conversation/turn 更新记录。自审按可读性、维护性、架构、正确性、权限、取消/恢复、性能、供应链与证据顺序执行；没有引入新的执行循环或权限写入口。
