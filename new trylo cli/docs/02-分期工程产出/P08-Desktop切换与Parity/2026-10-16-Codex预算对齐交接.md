## 结果与边界

普通执行取消默认 32 次请求和累计 65536 输出 token 两项额度；只在调用者明确配置时建立相应门禁。单次生成和思考遵循模型服务及用户配置，未自行发明新的统一输出上限或降低思考档位。声明窗口的 90% 是自动压缩阈值，配置窗口本身仍是发送硬上限；恢复会话首次发送前也检查。

执行日志为内部输入分配稳定、连续的 deliverySequence；状态机用处理进度去重，普通长流不再受 4096 个去重 id 的限制。旧格式输入仍保留原来的有界保护；混合模式、非法位置和缺口拒绝处理。重复旧工具请求不产生执行命令。领域拒绝消耗送达位置，后续取消仍可处理。日志依旧完整保留事件，内存随事件增长的问题没有在此次变成磁盘流式存储。

未改变权限、取消、tool call/result 配对、唯一终态、显式预算或 provider 截断失败的合同。旧设置文件中的预算值继续有效；不会自动迁移或修改用户配置。未改 CLI stream v1、持久化 session 格式或依赖闭包。
